# 源码导出范围

初始版本整理于 2026-10-20。`source_manifest.json` 记录白名单文件的原始 SHA256、导出 SHA256，以及是否应用适配。哈希用于核对来源，不包含机器路径或账户数据。

首尔运行环境与本地以下关键文件已在导出前逐一核对，原始哈希一致：主选币、Top50、v3 分位数、信号发布、换仓边界发布、日内前缀、分钟增量及源数据生产器。其余文件来自本地相应源项目。

导出只作以下适配，计算和优化公式保持源代码实现：

- 6 个 `live/deploy/` 模块的存储根目录改为 `SELECT_COIN_LIVE_ROOT`；默认指向仓库 `live/`。
- Optimizer 的默认 manifest 和资金费归档路径改为环境变量或包内 `data/`。研究输出保护改为根据输入 manifest 的实际冻结目录判断。
- Top50 测试共享的合成快照抽到 `tests/fixtures.py`，避免引入 API 服务与执行依赖。
- 旧质量测试的边界样本从历史 2% 更新为当前 10%，旧 600 小时量能样本更新为当前 599 小时输入格式；生产质量与选币代码不变。
- 历史 `config.py` 改为最小公开配置；`strategy.json` 来自已核验 v2 回测保存的策略设置。JSON 列表在加载时恢复为框架需要的元组。
- 清理 `core/equity.py` 和 `core/simulator.py` 的行尾空格。

旧代码中保留的 `shadow` / `candidate` 文件名和部分历史注释不代表当前上线状态；当前 v3 定义及发布路径以仓库 README 和 `top50_boundary_publish.py` 的参数为准。v2 函数同时作为历史基线及 v3 共用公式依赖保留。

没有导出：账户与执行配置、交易所密钥、下载授权链接、Webhook、服务器连接资料、真实订单/持仓/资金流水、原始数据、缓存、运行日志、PPT 与批量研究结果。仓库仅保留一张历史曲线及其汇总指标。

`tools/check_export.py --staged` 检查待提交的实际 Git blob，包括类型、大小、常见密钥特征、部署地址与路径、源码哈希和图片数量。它是发布前辅助检查，新增白名单仍需人工阅读差异。
