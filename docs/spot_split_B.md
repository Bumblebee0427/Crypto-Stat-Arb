# B：全市场过滤后分池40%/30%，每腿至少10币

版本：`bigultra_v3_global_top50_spot_split_l40_s30_min10_20261115_v1`。

按用户指令替换原实盘选币与权重，从2026-11-16 UTC00:00（北京时间08:00）正常日频换仓开始使用。部署不触发额外手工调仓。

## 计算顺序

1. 原有单币质量检查、当前v3逐笔因子、12日主因子线性衰减、小单多8日/空4日均值保留。
2. 在全市场各条腿的有效币中，独立计算成交额与小单因子的百分位。保留成交额前50%；小单多头百分位≥40%、空头≤35%。不在分池后重新计算这些过滤百分位。
3. 过滤后按当时可交易的币安USDT现货分成两个互斥组，两组均交易永续合约。现货映射使用官方公开名单和已知合约倍率/历史别名，并以决策前刚收盘的小时K线确认有成交。查询失败的币按未知排除，不当作无现货。
4. 每组每条腿按主因子排名：多头最高40%、空头最低30%，数量为 `min(N,max(floor(N*p),10))`；边界同值并列按最小排名纳入。候选不足10币时使用全部合格候选，空池预算留现金。
5. 每条腿预算对半分给两组，组内等名义金额。合并同币多空及重复空头腿后执行。B使用研究中的等权，不叠加旧25% optimizer混合。

账户杠杆乘数前的分配比例为：多头0.50、基础空头−0.225、额外空头−0.275；每组再乘0.50。执行端沿用既有2倍乘数、每日策略预算和总名义上限。额外空头保留原BTC趋势≤20%的条件与逐币上市历史要求，不能把最低10币理解为取消BTC保护。

## 与历史研究一致性

历史同输入比对覆盖2025-01-01至2026-10-21的659个日频目标：新实盘选币函数×2后，逐币权重与冻结B回测目标的最大绝对误差为0。独立pandas排名核验另覆盖合成边界同值、BTC缺失、空组、小时现货映射和网络失败。
